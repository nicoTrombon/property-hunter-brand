Barcelona · Apartment discovery

A clearer view of the apartment search.

Barcelona Property Hunter organizes Idealista email alerts, tracks listing prices and prepares a daily shortlist using the owner's location, budget and space preferences.

Personal-use project · No public registration

01 / Discover

Read property alerts delivered to a dedicated Gmail inbox, using the Gmail API with read-only permission.

02 / Keep perspective

Identify repeat listings and preserve price observations in a private SQLite database.

03 / Review

Rank listings with sufficient details. Keep missing information visible for manual verification.

Built for one apartment search

This is a personal automation, not an estate agency or a public Gmail service. Processing runs in a private GitHub repository through GitHub Actions. This public website only explains the project; it does not connect to Gmail or display private listings.

Gmail access, explained

The owner authorizes read-only Gmail access to find Idealista property alerts. The application does not send email, delete messages, or change labels or read status. Extracted property details are used for the private shortlist and price history.

Read the Privacy Policy for access, storage, retention and deletion details, or the Terms of Use for the project's limitations.
